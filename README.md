# VintageStory
These are my modified configs for rivers and watersheds.
The mod versions are:
rivers_5.0.3
watersheds_6.4.3

Other terrain generation mods I used:

  512HeightWatershedsLandforms
  
  terrainslabs_1.0.17
  
  rockstratavariety_0.0.4

  GeologyAdditions 1.4.8

  Conquest Blocklayer Overhaul v1.0.2

The main method I used to create these configs was pure brute force. Reading up on what values do what and then just changing them wildly till I got what I deemed to be good looking. Some of the changes I made are perhaps bad and can be improved or are really performance heavy. Those that actually know what each value does exactly should carefully look everything through before actually putting those values on their configs.
